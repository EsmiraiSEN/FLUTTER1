## Ответы на контрольные вопросы

### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Dart тип переменной проверяется на этапе компиляции, а в Python — динамически во время выполнения (рантайме). Практическое преимущество: компилятор Dart отлавливает ошибки несовместимости типов заранее, что предотвращает падение приложения у пользователя и улучшает работу автодополнения в IDE.

### 2. Что означает String?? Чем отличается от String?
* В Dart синтаксиса `String??` не существует (это может быть опечаткой или использованием оператора `??` после переменной).
* `String` — это гарантированно не-null строка.
* `String?` — это nullable-строка, которая может содержать как текст, так и значение `null`.

### 3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
"Договор" в Python не защищает от случайной перезаписи данных в крупном коде. Ключевое слово `final` в Dart жестко блокирует изменение переменной на уровне компилятора. Если разработчик попытается переназначить `final`-переменную, программа просто не скомпилируется, гарантируя стабильность константных данных.

### 4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
Именованный параметр передается по имени внутри фигурных скобок при вызове, и порядок аргументов не важен. Ключевое слово `required` делает его обязательным (без него код не скомпилируется). Позиционный параметр зависит строго от его порядкового места в объявлении функции.

**Пример вызова функции с именованным параметром:**
```dart
// Объявление
void printName({required String name}) { ... }

// Вызов
printName(name: 'Алексей');
```
